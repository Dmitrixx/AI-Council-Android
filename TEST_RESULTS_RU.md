# Результаты проверок AI Council 2.0.0

Последнее обновление: 21 октября 2026 года. Это рабочая промежуточная реализация; эти проверки не означают полного выполнения исходного технического задания.

## Выполнено в этой рабочей среде

- `python3 tools/verify_project.py`: **278/278** статических проверок пройдено.
- `JAVA_TOOL_OPTIONS=-XX:+UseSerialGC sh tools/desktop_smoke/run.sh`: завершился с кодом `0`; совокупно **362/362** автономные smoke-проверки. `CouncilExecutionEngineSmokeTest` — **30/30**, `ProviderModelsClientSmokeTest` — **9/9**, `WebSearchServiceSmokeTest` — **5/5**, `OcrInputPolicySmokeTest` — **18/18**, `OcrDocumentProcessorSmokeTest` — **5/5**. Среди регрессионных наборов `OcrModelManagerSmokeTest` — 16/16, `OcrModelIntegrityPolicySmokeTest` — 17/17, `WebSearchEndpointPolicySmokeTest` — 16/16 и `WebPageFetchPolicySmokeTest` — 23/23. Это локальные тесты; сетевые OkHttp stubs не ходят в интернет.
- `CouncilExecutionEngine.java`, `WebSearchClient.java`, `WebPageFetchClient.java`, `OcrModelManager.java`, `ProviderModelsClient.java` и `OcrDocumentProcessor.java` компилируются в desktop smoke runner с API-shape stubs для OkHttp/Android/OCR SDK. Это проверка Java-структуры и используемых методов, **не** замена Android-сборки с настоящим OkHttp и Android Gradle Plugin.
- Добавлен `OcrModelIntegrityPolicy`: закреплены точные размеры и SHA-512 для `rus.traineddata` (3 861 738 байт) и `ukr.traineddata` (3 825 102 байта) из `tessdata_fast` 4.1.0. Кэшированная модель проверяется перед использованием; новая проверяется по точному размеру и SHA-512 перед установкой.
- Загрузка/установка файлов перенесена из `MainActivity` в `OcrModelManager` и переведена на отдельный OkHttp-клиент с фиксированным HTTPS URL, проверкой публичных DNS-адресов с pinning, отключёнными редиректами, timeout-ами, проверкой `Content-Length`, потоковым лимитом размера, временным файлом и резервированием прежнего файла на время замены. Для OCR изображения и сканированного PDF подключён диалог отмены, закрывающий активный OkHttp Call.
- `OcrModelIntegrityPolicySmokeTest`: **17/17**, включая известный test vector SHA-512, и `OcrModelManagerSmokeTest`: **16/16**, включая досрочную отмену, отсутствие побочных файлов при отмене и классификацию отмены. Это unit-level проверки, а не тест реального скачивания upstream бинарников в этой среде.
- Поисковые API Brave Search, Tavily, Wikipedia/MediaWiki и DuckDuckGo Instant Answer JSON вынесены в `WebSearchClient` на OkHttp. Клиент использует тайм-ауты, ограничения размеров, отключённые редиректы, отмену активных вызовов и фиксированный список HTTPS API endpoints.
- В этом шаге вся оркестрация поиска перенесена из Activity в `WebSearchService`: параллельные источники, ранжирование/дедупликация, budget-ы страниц и безопасное извлечение plain text. `MainActivity` уменьшен на 386 строк — с 3577 до 3191. `WebSearchService` не импортирует Android API и покрыт 5 автономными smoke-тестами.
- Фото и PDF OCR вынесены в `ocr/OcrDocumentProcessor`; `MainActivity` уменьшен с 3191 до 2885 строк. Фото учитывает EXIF; результат содержит движок, число страниц и предупреждения. В текущем шаге PDF-страницы сначала проверяются на текстовый слой через PDFBox, а `PdfRenderer`/OCR запускаются только для страниц без извлекаемого текста. `OcrInputPolicySmokeTest` — 18/18; `OcrDocumentProcessorSmokeTest` — 5/5 на API-shape stubs.
- `WebSearchEndpointPolicy` запрещает произвольные hosts, HTTP, userinfo, неожиданные пути и нестандартные порты. Заголовок Brave `X-Subscription-Token` допускается только для Brave Search endpoint; `Api-User-Agent` — только для Wikipedia API. Ключ Tavily уходит заголовком `Authorization: Bearer …` только в вызове `https://api.tavily.com/search`.
- Добавлены поля настроек для необязательных ключей Brave и Tavily; оба ключа зашифровываются при сохранении, исключены из backup и учитываются в локальной проверке секретов перед отправкой.
- `MainActivity` отменяет активные поисковые, чатовые и model-catalog OkHttp-вызовы при остановке задачи. HTML-загрузку выполняет `WebPageFetchClient` на OkHttp с DNS-проверкой и закреплением адресов, повторной проверкой redirect target, ограничением MIME type/размера и отменой вызовов.
- Версия проекта: `versionName 2.0.0`, `versionCode 47`, `compileSdk 36`, `targetSdk 36`. В зависимости уже включён OkHttp 4.12.0.

## Не выполнено или не проверено

- Полная Android-сборка (`assembleDebug`) в этой среде не запускалась: Android SDK и Gradle отсутствуют. Настоящий Android compile/runtime и сборка APK не подтверждены, APK не приложен.
- Реальные запросы к Brave/Tavily не выполнялись: в рабочей среде нет предоставленных API credentials. Smoke-тесты проверяют локальную политику URL и заголовков, а не внешний сервис/тариф/квоты.
- GitHub Actions workflow удалённо не запускался из этой среды, его артефакт не подтверждён.
- Приёмка на физическом Android-телефоне с 6 ГБ RAM и на планшете не выполнялась. Чек-лист раздела 10 исходного задания **не пройден**.
- `CouncilExecutionEngine` вынесен в отдельный Android-независимый Java-класс: режимы quick/audit/council/deep, параллельные независимые ответы, раунд взаимной критики, координация, статусы и обработка частичного отказа покрыты 30 автономными проверками. `MainActivity` уменьшен с 3191 до 2885 строк после выноса поиска, OCR и упрощения PDF-импорта, но остаётся крупным классом; разделение на полноценные экраны/слои и ViewModel/задачу завершено не полностью.
- `HttpURLConnection`/`URL.openConnection()` больше не используются в исходниках приложения: запросы чата, поисковых API, HTML-страниц, OCR-моделей и `/models` вынесены в отдельные OkHttp-клиенты. Форматирование и статусный адаптер UI остаются в `MainActivity`, но оркестрация поиска, ранжирование и обработка HTML теперь находятся в `WebSearchService`.
- OCR-загрузчик использует отдельный OkHttp-клиент, проверяет адрес назначения и контрольную сумму модели, а UI отменяет активную загрузку. Поддерживаются только `rus` и `ukr`; расширяемый каталог, end-to-end тест реальных скачиваний и тест на устройстве не выполнены.
- Встроенная модель отсутствует: llama.cpp, NDK/JNI, каталог GGUF, загрузка весов, контроль RAM и автономная генерация Qwen 1.5B/3B не реализованы или не проверены.
- Network Security Config не поддерживает диапазоны IPv4; cleartext HTTP на произвольный частный LAN IP может блокироваться. Совместимость Ollama/LM Studio по локальному IPv4 не подтверждена на устройстве.

## Итог

В последних итерациях `OcrModelManager` переведён на OkHttp, добавлена DNS-проверка с pinning и UI-отмена активной загрузки для OCR изображений и PDF; `OcrDocumentProcessor` обрабатывает PDF по гибридной схеме: PDFBox text layer, затем локальный OCR только на страницах без текста, а ранее были выделены `CouncilExecutionEngine` и `WebSearchService`; сборочная конфигурация обновлена до AGP 9.4.0 / Gradle 9.6.0. Целостность `rus`/`ukr` проверяется по закреплённому размеру и SHA-512 для кэша и до установки; `OcrModelIntegrityPolicySmokeTest` — 17/17 и `OcrModelManagerSmokeTest` — 16/16. Ранее добавленные `WebSearchClient` и `WebPageFetchClient` остаются отдельными OkHttp-клиентами, Tavily — дополнительным поисковым источником. Проект по-прежнему является **частичной реализацией 2.0.0**, не готовым проверенным APK-релизом и не полным выполнением большого технического задания.
