# Как получить APK через GitHub Actions

В этой среде не установлены Android SDK и Gradle, поэтому готовый APK не приложен. В проекте добавлен workflow `.github/workflows/android-build.yml`, который проверяет исходники 2.0.0 и собирает debug APK на сервере GitHub. Workflow также создаёт SHA-256 для собранного APK.

## Первый запуск

1. Создайте пустой репозиторий на GitHub. Не добавляйте туда реальные API-ключи, пароли или личные резервные копии AI Council.
2. Загрузите содержимое проекта в репозиторий, включая папки `.github/workflows`, `app`, `tools` и файлы `build.gradle` / `settings.gradle`.
3. Откройте вкладку **Actions** репозитория и выберите workflow **Android CI**. Обычно он запустится автоматически после push; при необходимости откройте workflow и нажмите **Run workflow**.
4. Дождитесь зелёного статуса `verify-and-build`. После успешной сборки внизу страницы запуска появится **Artifacts** с архивом `aicouncil-debug-apk-…`. Внутри будут `app-debug.apk` и файл SHA-256.
5. Скачайте архив, распакуйте его. Сверьте SHA-256, если умеете проверять хеши, затем скопируйте `app-debug.apk` на Android-телефон и откройте его для установки. В настройках Android может потребоваться разрешить установку приложения из выбранного источника.

## Что делает workflow

- Запускает `tools/verify_project.py` и desktop smoke tests.
- Подготавливает JDK 17, Android SDK 36 и Gradle 9.6.0.
- Выполняет статические проверки и автономные Java smoke tests, затем `gradle assembleDebug`.
- Проверяет, что APK существует и не пуст, генерирует SHA-256 и загружает оба файла как временный artifact на 14 дней.
- Запускается при push, pull request или вручную через `workflow_dispatch`.

Это debug-сборка для тестирования, не подписанный Play Store релиз. Проверки приватности 1.37.0 (унаследованные проверки) включают предупреждение перед отправкой текста, похожего на секрет, но не гарантируют обнаружения всех секретов и не сканируют бинарные вложения полностью. Она не является подтверждением работы на всех телефонах: после установки проверьте создание задач, тест подключения моделей, поиск, импорт документов/OCR и резервное копирование. Для версии 2.0.0 workflow настроен на Android SDK 36 / Gradle 9.6.0. Его реальный запуск в GitHub всё ещё необходимо подтвердить; локально Android SDK и Gradle недоступны.
