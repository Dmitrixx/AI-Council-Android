# Desktop smoke tests AI Council 1.30.0

Запуск из корня проекта:

```sh
JAVA_TOOL_OPTIONS='-XX:+UseSerialGC' sh tools/desktop_smoke/run.sh
```

Текущий набор содержит **132 теста**: 5 проверок извлечения DOCX/XLSX и безопасного отказа на неподдерживаемых форматах; 12 проверок политики API URL; 26 проверок поискового запроса, URL и эвристики ранжирования; 17 проверок local-only, `/models`, передачи ключей и независимости local-only от web search; 8 проверок fingerprint конфигурации; 7 проверок Markdown-отчёта; 8 проверок политики взаимной критики; 10 проверок пользовательских ролей; 10 проверок определения секции для продолжения ответа; 29 проверок выбора системной/светлой/тёмной темы, цветовой адаптации и контраста.

Android `Context` и отдельные PDFBox API для desktop-запуска подменяются тестовыми заглушками только для компиляции общего экстрактора. Эти тесты не проверяют фактическое извлечение PDF, Android UI, OCR, Gradle-сборку или сетевое подключение к Brave/Wikipedia/DuckDuckGo/Ollama/LM Studio. Они не заменяют тесты на физическом устройстве.
