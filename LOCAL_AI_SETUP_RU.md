# Настройка интернета и локального ИИ — AI Council 1.26.0

Это практическое руководство для версии 1.26.0. Оно описывает настройку поиска в Интернете и подключение AI Council к локальному OpenAI-совместимому серверу Ollama или LM Studio.

## 1. Поиск в Интернете

### Без ключа

1. Откройте AI Council и включите **«Искать в Интернете · независимо от режима ИИ»**.
2. Приложение параллельно запрашивает Brave Search (при наличии токена), Tavily Search (при наличии ключа), Wikipedia Search через MediaWiki API и DuckDuckGo Instant Answer. DuckDuckGo HTML scraping удалён. Без настроенного Brave/Tavily остаются Wikipedia и DuckDuckGo Instant Answer, но они могут не дать полноценную поисковую выдачу.
3. Выберите объём веб-контекста: только заголовки и ссылки (страницы не скачиваются), короткие поисковые выдержки (только выдача поиска) или выдержки плюс извлечение текста до двух исходных страниц. Последний режим может работать дольше и отправляет больше контента выбранным моделям.
4. Результаты располагаются по эвристической оценке совпадения слов запроса и типа домена. Это помогает отсортировать кандидатов, но не подтверждает достоверность источника. Сайты с JavaScript, CAPTCHA, ограничением доступа или без HTML могут не дать содержимое.
5. Для извлечённых страниц дата из метаданных публикации/изменения показывается отдельно от даты извлечения. Дату, заданную сайтом, следует считать неподтверждённой.

### Расширенный поиск Brave Search (необязательно)

1. Получите API-токен в официальном кабинете Brave Search API: <https://api-dashboard.search.brave.com/>
2. В приложении нажмите **«Настроить ключи веб-поиска»**, вставьте токен и сохраните.
3. Токен передаётся только `https://api.search.brave.com` в заголовке `X-Subscription-Token`. Он хранится на устройстве в зашифрованном виде через Android Keystore, а в резервную копию не включается.
4. Токен может требовать активации тарифа или иметь квоты. Если Brave вернул ошибку, приложение продолжит попытки поиска по остальным доступным источникам.

Для поиска приложение отправляет очищенную фразу длиной не более 180 символов. Для запросов с явным указанием актуальности Brave Search получает фильтр свежести: последние сутки, неделю, месяц или год. Внешняя служба может сообщать дату страницы, но это не гарантия даты публикации. Не включайте интернет-поиск для конфиденциальных задач: фраза уходит внешним поисковым службам, а найденные сниппеты и выдержки могут передаваться настроенным моделям ИИ.

### Tavily Search (необязательно)

1. Получите API-ключ в официальном кабинете Tavily: <https://app.tavily.com/>.
2. Нажмите **«Настроить ключи веб-поиска»** и вставьте ключ в поле Tavily. Ключ шифруется перед хранением.
3. При запросах со словами, указывающими на актуальность, приложение использует режим новостей и фильтр времени (сутки/неделя/месяц/год); обычные вопросы используют общий поиск.
4. Ключ отправляется в заголовке `Authorization: Bearer …` только на `https://api.tavily.com/search`. Ошибки отдельного поискового канала не должны блокировать доступные остальные каналы. Доступность, лимиты и тарифы проверяются в аккаунте Tavily.

Поисковые API выполняются через отдельный OkHttp-клиент с фиксированным allowlist HTTPS endpoints, отключёнными редиректами, ограничением размера ответа и отменой активных запросов. Получение текста самих найденных страниц — отдельная операция, которая может обращаться к сайтам из результатов и передавать извлечённые выдержки выбранным AI-моделям.

## 2. Подготовьте локальную модель

Для этого режима нужен компьютер в той же доверенной Wi-Fi-сети, что и телефон. Компьютер запускает модель и обрабатывает запросы; AI Council служит клиентом к API. Эта версия **не содержит встроенную модель и не выполняет полностью автономный inference внутри APK**.

### Вариант A — Ollama

1. Установите Ollama с официального сайта: <https://ollama.com/>.
2. Скачайте подходящую модель, например командой `ollama pull llama3.2`. Перед загрузкой проверьте размер модели и возможности оперативной памяти компьютера.
3. Проверьте идентификатор доступной модели командой `ollama list`.
4. По умолчанию сервер Ollama обычно доступен только на `127.0.0.1:11434`. Для подключения с телефона настройте его прослушивание локального интерфейса, например переменной окружения `OLLAMA_HOST=0.0.0.0:11434`, и перезапустите сервер. Способ задания переменной зависит от ОС и способа запуска Ollama; сверяйтесь с актуальным руководством: <https://docs.ollama.com/faq>.
5. Разрешите входящие подключения к порту `11434` только из частной локальной сети в брандмауэре. Не публикуйте порт в Интернет и не настраивайте проброс порта на роутере.

В AI Council выберите быстрый пресет **«Локальная модель · Ollama по Wi-Fi»**, замените `192.168.1.100` на локальный IPv4 компьютера и укажите точный ID из `ollama list` (например `llama3.2`). Базовый URL имеет вид `http://IP-КОМПЬЮТЕРА:11434/v1`.

### Вариант B — LM Studio

1. Установите LM Studio: <https://lmstudio.ai/>.
2. Скачайте совместимую с вашим компьютером модель, загрузите её в LM Studio и откройте вкладку **Developer**.
3. Запустите **Local Server**. Чтобы обращаться с телефона, включите **Serve on Local Network**. Прочитайте адрес, который показывает приложение; порт по умолчанию часто `1234`, но используйте фактический адрес и порт.
4. Рекомендуется включить аутентификацию, если сервер доступен с других устройств. Настройте брандмауэр так, чтобы к серверу могли обращаться только нужные устройства из доверенной сети. Не выставляйте сервер напрямую в публичный Интернет.
5. В AI Council выберите **«Локальная модель · LM Studio по Wi-Fi»**, замените IP на фактический IP компьютера и введите идентификатор загруженной модели, который сообщает LM Studio. Базовый URL обычно имеет вид `http://IP-КОМПЬЮТЕРА:1234/v1`.

Официальное руководство LM Studio: <https://lmstudio.ai/docs/developer/core/server/serve-on-network>.

## 3. Подключите сервер в AI Council

1. В настройках одного из трёх слотов ИИ выберите пресет Ollama или LM Studio.
2. Замените примерный IP на фактический LAN IPv4 компьютера. Телефон и компьютер должны быть в одной сети и не изолированы друг от друга настройками Wi-Fi.
3. Укажите точный ID уже загруженной модели. Список имён зависит от выбранного сервера и скачанной модели.
4. Для распознанного локального HTTP- или HTTPS-адреса можно оставить ключ пустым. AI Council не отправляет сохранённый облачный ключ в локальный endpoint (независимо от HTTP/HTTPS).
5. Нажмите **«Получить список моделей»**, выберите точный ID в списке (если сервер поддерживает `/v1/models`), затем нажмите **«Проверить подключение»**. Короткий тестовый запрос будет обработан выбранной моделью.
6. Для защиты от случайной отправки задачи в облако включите **«Только локальные ИИ · блокировать облачные API»**. Перед запуском приложения проверяйте, что нужные слоты действительно настроены на локальные адреса. Этот переключатель не управляет поиском в Интернете: если включена галочка веб-поиска, поисковая фраза отправляется внешним поисковым службам, а найденные результаты могут передаваться локальной модели. Для полностью локальной работы отключите веб-поиск отдельно. Пока задача выполняется, переключение режима приватности и веб-поиска заблокировано; сначала остановите текущую задачу.

## 4. Конфиденциальность и безопасность

- Обычный HTTP в Wi-Fi-сети не шифрует запросы. Используйте только доверенную сеть; для более строгой защиты настройте HTTPS reverse proxy и проверенную конфигурацию сертификатов.
- Не пробрасывайте порты Ollama/LM Studio из Интернета и не используйте такие серверы на публичном Wi-Fi.
- Режим «Только локальные ИИ» блокирует облачные AI API, но не веб-поиск. Внешние поисковые API и страницы вызываются только тогда, когда отдельно включена галочка интернет-поиска.
- Локальное выполнение не означает автоматическую приватность всего сетевого окружения: любой клиент, которому доступен незакрытый LAN-сервер, может пытаться отправлять ему запросы.
- Качество и скорость зависят от модели, памяти, процессора/видеокарты и настроек сервера.

## 5. Если соединение не работает

1. Убедитесь, что сервер запущен и модель загружена.
2. Сверьте локальный IP компьютера, порт и точный ID модели.
3. Проверьте, что телефон и компьютер соединены с одной сетью и межустройственная изоляция отключена.
4. Проверьте правила брандмауэра; разрешите только приватную сеть.
5. Для Ollama проверьте, что он слушает LAN-интерфейс, а не только `127.0.0.1`.
6. Для LM Studio проверьте, что активна настройка **Serve on Local Network** и сервер показывает нужный LAN-адрес.
7. Не используйте `localhost` в конфигурации телефона для сервера, запущенного на компьютере: `localhost` на телефоне указывает на сам телефон.
8. При ошибке 404/модели проверьте правильность базового URL и ID модели. Приложение добавляет `/chat/completions` к базовому `/v1`.
