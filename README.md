# AI Council 3.46.0

Local focusing-illusion and illusion-of-control checks flag a verdict that (1) treats one salient attribute — salary, status, location, a single metric — as determining overall value without stating other dimensions, trade-offs or adaptation, or (2) treats skill/strategy as decisive in a noisy domain without residual randomness, base rates of outcomes, or limits of influence. Naming those gaps is not itself an error. The coordinator cannot close on the focused attribute or claimed control alone. Version on screen matches Gradle: `3.46.0` / versionCode `213`.

Also restored the full programmatic council UI in `MainActivity` (was reduced to a version stub on main).

# AI Council 3.45.0
