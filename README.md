# AI Council 2.36.0

**Multi-provider AI council for Android** — independent answers, audits, deep analysis, local servers, source search, document import and report export.

The installed version stays `2.36.0` (versionCode 103). Local brain notes through 2.78.0 add loss aversion: a heavier feeling of loss is not a coefficient, and it is not a reason to skip expected value. On top of the four-slot council, the local synthesis protocol classifies a task as a decision, forecast, fact check, design, explanation, or general review and tells the experts how to answer. A levered or all-in question also gets an ergodicity check: a positive average is not a reason to bet a stake that one loss can wipe out. The coordinator must not raise confidence just because the wording agrees, and must not average incompatible claims. Decision questions end with DO / DON'T / CHECK FIRST. Logical-risk, calibration, pre-mortem, outside-view, sensitivity, tail-risk, opportunity-cost, Goodhart, sunk-cost, ergodicity, confirmation-bias and causal signals remain hypotheses that need context, not automatic verdicts.
