# AI Council 3.7.0

A local argument-from-personal-incredulity check now flags conclusions that something is false or impossible merely because the speaker cannot imagine or understand how it could be true. Naming that error is not itself an error. The coordinator cannot close a verdict on personal incredulity alone, and experts on a structured task are told that inability to comprehend is not evidence. # AI Council 3.6.0

A local appeal-to-fear check now flags conclusions that something is true, good, necessary, or preferable merely because it is scary, threatening, or because failing to act would be catastrophic. Naming that error is not itself an error. The coordinator cannot close a verdict on fear or threat alone, and experts on a structured task are told that fear is not an argument. Version on screen matches Gradle: `3.6.0` / versionCode `173`.

# AI Council 3.5.0

The council now keeps the unseen cost on the ledger and refuses to treat an easy metric as the whole decision. `SeenAndUnseenPolicy` flags a verdict that counts only the visible effect (Bastiat: the broken window is not a gain). `StreetlightPolicy` flags a verdict that keeps only what is easy to measure (McNamara / streetlight). Naming either error is not itself an error. When such a signal is on the local map, `CoordinatorCue` tells the coordinator the exact way not to close — novelty, pity, a red herring, tu quoque and the other unwired hypotheses now get a specific instruction too, capped at four notes so the task is not drowned. Experts are told the same rule in the shared baseline. Version on screen matches Gradle: `3.5.0` / versionCode `172`.
