# AI Council 2.98.0

**Multi-provider AI council for Android** — independent answers, audits, deep analysis, local servers, source search, document import and report export.

The installed version is `2.98.0` (versionCode 165). The local brain now separates valid inference from two formal errors: affirming the consequent (an effect is not proof of one cause) and denying the antecedent (a failed sufficient condition does not refute the effect). Modus ponens and modus tollens stay valid. Naming the fallacy is not the error. Experts on a structured task are told the distinction, and the coordinator cannot close a verdict on either fallacy. False equivalence from 2.97.0 is now actually enforced in the coordinator map, and the on-screen version matches Gradle again.

Logical-risk signals remain hypotheses that need context, not automatic verdicts.
