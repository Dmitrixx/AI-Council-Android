# AI Council 3.21.0

A local impact-bias / affective-forecasting check now flags a verdict that treats a predicted strong emotional reaction (joy, regret, fear of missing out) as sufficient reason to choose or avoid an option, without independent justification that the feeling will actually occur at that intensity or duration. Naming that error is not itself an error. The coordinator cannot close on anticipated emotion alone, and experts on a structured task are told that predicted feelings are often overestimated in both intensity and duration. Version on screen matches Gradle: `3.21.0` / versionCode `188`.

# AI Council 3.20.0

A local causal-oversimplification / single-cause check now flags a verdict that attributes a complex multi-factor outcome to one simple cause without independent justification for exclusivity. Naming that error is not itself an error. The coordinator cannot close on a single cause alone, and experts on a structured task are told that a complex result requires considering contributing factors. Version on screen matches Gradle: `3.20.0` / versionCode `187`.

# AI Council 3.19.0

A local data-dredging / garden-of-forking-paths check now flags a verdict that treats a pattern found after searching many hypotheses, subgroups or model specifications without pre-registration or multiple-comparison correction as confirmation. Naming that error is not itself an error. The coordinator cannot close on an uncorrected hit after forking paths, and experts on a structured task are told that a pattern found by searching is not independent evidence. Version on screen matches Gradle: `3.19.0` / versionCode `186`.
