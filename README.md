# AI Council 3.40.0

A local better-than-average / illusory-superiority check now flags a verdict that treats the decision maker, group or option as above average on a desirable trait or chance without independent evidence or a base-rate comparison. Naming that gap is not itself an error. The coordinator cannot close on the self-flattering ranking alone. Version on screen matches Gradle: `3.40.0` / versionCode `207`.

# AI Council 3.39.0

A local backfire-effect / belief-polarization check now flags a verdict that treats contrary evidence as strengthening the original belief rather than requiring an update or explicit acknowledgment of the counter-evidence's force. Naming that gap is not itself an error. The coordinator cannot close on the strengthened prior once contrary observations are named. Version on screen matches Gradle: `3.39.0` / versionCode `206`.

# AI Council 3.38.0

A local wishful-thinking / motivated-reasoning check now flags a verdict that closes on a preferred or pleasant outcome as if the desire were evidence of likelihood, or that discounts contrary evidence because the conclusion is unwelcome, without independent justification. Naming that gap is not itself an error. The coordinator cannot close on the desired outcome alone. Version on screen matches Gradle: `3.38.0` / versionCode `205`.
