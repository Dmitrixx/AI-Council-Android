# AI Council 3.49.0

A local value-of-information check now flags a verdict that treats immediate action as decisive without stating the cost and expected value of gathering more information, whether that information could change the decision, reversibility, or the opportunity cost of delay. Naming that gap is not itself an error. The coordinator cannot close on "act now" alone. Version on screen matches Gradle: `3.49.0` / versionCode `216`.

# AI Council 3.48.0

A local illusion-of-validity check now flags a verdict that treats a coherent, confident, internally consistent story or model as decisive evidence of correctness or predictive power without stating out-of-sample checks, base rates, alternative narratives, or calibration against outcomes. Naming that gap is not itself an error. The coordinator cannot close on narrative coherence or confidence alone. Version on screen matches Gradle: `3.48.0` / versionCode `215`.

# AI Council 3.46.0

Local focusing-illusion and illusion-of-control checks flag a verdict that (1) treats one salient attribute — salary, status, location, a single metric — as determining overall value without stating other dimensions, trade-offs or adaptation, or (2) treats skill/strategy as decisive in a noisy domain without residual randomness, base rates of outcomes, or limits of influence. Naming those gaps is not itself an error. The coordinator cannot close on the focused attribute or claimed control alone. Version on screen matches Gradle: `3.46.0` / versionCode `213`.
