# Текущий этап — гибридный OCR PDF (2.0.0)

- `OcrDocumentProcessor` сначала извлекает текстовый слой каждой PDF-страницы через PDFBox. Android `PdfRenderer` запускается только для страниц без извлекаемого текста; OCR применяется только к ним. Обычный PDF-импорт и OCR с выбором языка используют общий обработчик.
- Предпросмотр маркирует страницы и показывает, где текст не удалось распознать. Исходный PDF/фото остаётся на устройстве; сеть используется лишь для однократной загрузки выбранной языковой модели Tesseract при необходимости.
- `OcrInputPolicy` удерживает 10 MiB входной лимит, 3200 px длинной стороны/12 млн пикселей для фото, 5 страниц по умолчанию (policy поддерживает запрос до 20, но UI выбора лимита не подключён), 90 000 символов и безопасное имя файла.
- Проверки: `tools/verify_project.py` — **278/278**; `tools/desktop_smoke/run.sh` — **362/362**, включая `OcrInputPolicySmokeTest` (18/18) и `OcrDocumentProcessorSmokeTest` (5/5). Последний использует API-shape stubs и не заменяет устройство.
- Следующее: вынести ещё экранную логику из `MainActivity`, подключить пользовательский выбор числа страниц и отмену на всех путях импорта; затем продолжать миграцию OCR экрана/настроек. Gradle/APK и реальное устройство пока не проверены.

## Историческая запись: выполнено в 1.37.0

## Продолжение разработки 2.0.0 — единый защищённый загрузчик страниц

- HTML-страницы результатов поиска теперь загружает `WebPageFetchClient` на OkHttp, а не собственный `HttpURLConnection` цикл в `MainActivity`.
- Для HTTP-запроса выполняется проверка URL и HTTPS-порта; каждый DNS-ответ проверяется на частные, loopback, link-local и special-use адреса. Проверенный список адресов напрямую возвращается OkHttp DNS resolver, чтобы не выполнять повторное разрешение имени после проверки.
- Редиректы отключены на уровне клиента и обрабатываются вручную, каждый следующий адрес повторно проходит URL-политику; разрешены максимум два перехода. Текстовые страницы ограничены размером 300 KB, MIME type — HTML/XHTML, тайм-аут запроса — 5 секунд.
- Отмена запроса и завершение дедлайна теперь отменяют активные вызовы загрузчика страниц. Добавлен `WebPageFetchPolicySmokeTest` (23 проверки); совокупно 262 автономные smoke-проверки.
- Ограничение: на момент этой записи каталог моделей всё ещё использовал `HttpURLConnection`; позже этот путь выделен в `ProviderModelsClient` на OkHttp. Приёмка на устройстве и реальная сетёвая проверка всё равно обязательны.

## Продолжение разработки 2.0.0 — выделение клиента каталога моделей

- `GET /models` вынесен из `MainActivity` в `ProviderModelsClient` на OkHttp. В Activity оставлена координация интерфейса, проверка результата и выбор модели.
- Транспорт ограничивает тело ответа 250 КБ, отключает автоматические редиректы, имеет connect/read/write/call timeout и отслеживает активные вызовы для явной отмены.
- Запросы проверяются через `LocalAiPolicy`/`EndpointPolicy`; локальным endpoint-ам ключ не добавляется, режим «Только локальные ИИ» не допускает сетевой вызов к публичному API. Ошибка форматируется через `ProviderErrorFormatter` и маскируется `SecretRedactor`.
- Добавлен автономный `ProviderModelsClientSmokeTest` на 9 проверок, включая локальную границу credentials и классификацию отмены. Это не заменяет сборку APK или настоящий вызов к провайдеру.
