# AI Council 2.0.0 — рабочие заметки к сдаче

> Статус: промежуточная реализация задания, не подтверждённый APK-релиз. Актуальная сборочная конфигурация — AGP 9.4.0 / Gradle 9.6.0 / API 36. Сборка и проверка на устройстве остаются обязательными перед публикацией.

## Включено
- OCR изображений и PDF вынесен в `OcrDocumentProcessor`; PDF обрабатывается по гибридной схеме: PDFBox text layer на каждой странице, Android `PdfRenderer` и OCR только для страниц без текста. Загрузка и установка моделей OCR `rus`/`ukr` вынесена в `OcrModelManager` и переведена на OkHttp. Для фиксированного HTTPS-источника проверяются публичные DNS-адреса с pinning, редиректы отключены, файлы версии `tessdata_fast` 4.1.0 проверяются по точному размеру и SHA-512 перед установкой и при повторном использовании. Кнопка «Отменить загрузку» подключена для OCR изображений и сканированного PDF.
- Версия приложения: 2.0.0 (versionCode 47).
- Android Gradle Plugin 9.4.0, Gradle 9.6.0, compileSdk/targetSdk 36.
- В `.github/workflows/android-build.yml` настроен запуск статических проверок, desktop smoke и `assembleDebug` на push/PR с публикацией APK + SHA-256 как artifact; удалённый запуск workflow из этой среды не подтверждён.
- HTML scraping DuckDuckGo удалён, остаётся JSON Instant Answer. Добавлен Tavily как необязательный полнотекстовый источник.
- Поисковые API Brave/Tavily/Wikipedia/DuckDuckGo переведены на отдельный OkHttp-клиент с фиксированным HTTPS allowlist, ограничением размера ответа и отменой активных запросов. Загрузка исходных HTML-страниц остаётся отдельной guarded-операцией.
- Убран глобальный `usesCleartextTraffic=true`, добавлен Network Security Config.

## Блокирующие незавершённые пункты полного задания
- Разделение MainActivity на экраны/слои не завершено.
- `POST /v1/chat/completions`, поисковые API, страницы источников, OCR-модели и каталог `/models` используют отдельные OkHttp-клиенты. В `app/src/main/java` не осталось `HttpURLConnection` / `URL.openConnection()`; это подтверждается статическим поиском, но не является доказательством корректности всех Android network scenarios.
- История/проекты/черновик перенесены в локальную SQLite через `SQLiteOpenHelper`, с миграцией пяти legacy-ключей по allow-list. Room не используется.
- Сетевой модуль поиска выделен в `WebSearchClient` для API-запросов, но общий сетевой слой не полностью вынесен из `MainActivity`; live API-проверка Tavily/Brave и обработка реальных ключей ещё не выполнены.
- `OcrModelManager` отделяет файловую загрузку OCR от `MainActivity`; общий переиспользуемый экземпляр OkHttp для всех сетевых модулей и расширяемый каталог языков ещё не завершены. Для двух поддерживаемых моделей включена проверка SHA-512 и пользовательская отмена загрузки.
- llama.cpp/JNI, каталог GGUF, проверка свободной RAM и генерация offline не реализованы.
- Не выполнялась инструментальная сборка в этой среде и не было физического устройства для проверки 6 ГБ RAM.
- Android Network Security Config не поддерживает диапазоны IPv4; произвольные HTTP endpoints по LAN IP требуют отдельного решения.

Текущие автономные проверки в этой рабочей итерации: `verify_project.py` — 278/278; desktop smoke — 362/362. Desktop-слой использует API-shape stubs для Android/OCR и не подтверждает настоящий Android compile/runtime. Не использовать эту запись как утверждение о полном прохождении раздела 10 приёмки: Gradle/APK и физическое устройство остаются непроверенными.
