# AI Council 3.51.0

Локальная проверка внешней валидности теперь отмечает вердикт, который переносит результат другой популяции, лаборатории, страны или прошлого режима на этот случай и закрывает выбор без причины, почему механизм переносится. Назвать пробел — не ошибка. Координатор не закрывает вопрос чужим результатом «как есть». Версия на экране совпадает с Gradle: `3.51.0` / versionCode `218` .

Назвать пробел — не ошибка. Координатор не закрывает вопрос одним относительным процентом. Версия на экране совпадает с Gradle: `3.45.0` / versionCode `212` .

Назвать пробел — не ошибка. Координатор не закрывает вопрос одним желаемым исходом. Версия на экране совпадает с Gradle: `3.38.0` / versionCode `205` .
