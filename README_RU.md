## 2.63.0 — Focusing illusion

- Добавлен `FocusingIllusionPolicy`: локально замечает вывод, что один яркий фактор («только это важно», «всё зависит от дохода», «this metric decides everything») определяет общую ценность без учёта остальных факторов, адаптации и компромиссов.
- Отдельный сигнал, если оба эксперта переоценивают влияние одного фактора.
- Сигнал участвует в карте разногласий. Это гипотеза, требующая контекста, а не вердикт. Gradle / APP_VERSION теперь `2.63.0` / versionCode `130`.

## 2.62.0 — IKEA effect

- Добавлен `IKEAEffectPolicy`: локально замечает вывод, что частично созданное/собранное/настроенное мной («собрал сам поэтому лучше», «because I built it», «my effort makes it better») ценнее эквивалентной альтернативы без независимой оценки качества или рыночного сравнения.
- Отдельный сигнал, если оба эксперта завышают ценность результата собственного труда без внешней калибровки.
- Сигнал участвует в карте разногласий. Это гипотеза, требующая контекста, а не вердикт. Gradle / APP_VERSION теперь `2.62.0` / versionCode `129`.
