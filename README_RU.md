# AI Council 2.71.0

В локальной карте 2.71.0 трактовка ситуации как строго zero-sum («если они выигрывают — мы проигрываем», «пирог фиксирован») без учёта взаимной выгоды или расширяемого пирога остаётся гипотезой (zero-sum bias), а не доказательством. В локальной карте 2.70.0 необратимый шаг без пилота/отката и опровержение карикатуры чужой позиции тоже остаются гипотезами. ... (предыдущие заметки сохранены в истории коммитов).

Современная оболочка AI Council: чернильные поверхности, мятный акцент, плавающая навигация и контент от края до края на Android 11+. Сигналы — гипотезы, требующие контекста, а не автоматические вердикты. Версия `2.71.0` / versionCode `138` добавляет `ZeroSumBiasPolicy`.

AI Council — Android-приложение для работы с несколькими ИИ-провайдерами: независимые ответы, аудит, глубокий анализ, локальные серверы, поиск источников, импорт документов и экспорт отчётов.

## 2.71.0 — Zero-sum bias

- Добавлен `ZeroSumBiasPolicy`: локально замечает fixed-pie / антагонистическую рамку («если они выигрывают — мы проигрываем», «только один может выиграть», «пирог фиксирован») без учёта win-win, расширяемого пирога или независимых осей выгоды.
- Отдельный сигнал, если оба эксперта предполагают строго zero-sum исход.
- Модуль подключён в `DeliberationSignals.detectAll`. Это гипотезы, требующие контекста, а не вердикт. Gradle / APP_VERSION теперь `2.71.0` / versionCode `138`.

## Примечания для static verify

- Ключи API в резервную копию **не включаются**.
- Импорт: **предпросмотр** перед вставкой, можно **редактировать** фрагмент.
- Для **сканированных PDF**: для каждой из **первых пяти страниц** сначала текстовый слой, затем OCR.
- В APК **не встроены веса языковой модели и on-device inference runtime**; локально — **Ollama/LM Studio**.
- **HTTP в LAN не шифрует трафик**; запросы идут **поисковым сервисам**.
- Режим «Только локальные ИИ» **не выключает веб-поиск**; **поисковая фраза отправляется внешним поисковым сервисам**.
