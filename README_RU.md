# AI Council 3.60.0

Обновлён основной экран: фирменный знак в заголовке, более последовательная типографика и геометрия карточек, заметное состояние фокуса полей и увеличенные зоны нажатия инструментов. Выбор режима совета теперь корректно восстанавливается после перезапуска и имеет контрастную подсветку в светлой и тёмной темах. Добавлены UI-проверки брендинга, статуса и доступности.

Полный исходный код `MainActivity.java` теперь хранится в репозитории. CI больше не подменяет неполный исходник скачанным скрытым снимком: неполный файл приводит к явной ошибке статической проверки. Исправлена сигнатура Android UI smoke-теста, который ранее не компилировался. Версия Gradle и экрана: `3.60.0` / versionCode `228`.

Локальная проверка эффекта компромисса теперь отмечает вердикт, который принимает средний вариант за решающий только потому что он компромисс между крайностями, без абсолютной ценности по ключевым измерениям или независимого сравнения. Назвать пробел — не ошибка. Координатор не закрывает вопрос одной позицией «середина». Версия на экране совпадает с Gradle: `3.53.0` / versionCode `220`.
