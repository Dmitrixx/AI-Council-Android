# AI Council 2.72.0

В локальной карте 2.72.0 утверждение, что данные совместимы только с одним механизмом («единственное возможное объяснение», «другого объяснения нет»), без соперничающей гипотезы на тех же наблюдениях, остаётся гипотезой (underdetermination), а не доказательством. В локальной карте 2.71.0 трактовка ситуации как строго zero-sum без учёта взаимной выгоды тоже остаётся гипотезой. ... (предыдущие заметки сохранены в истории коммитов).

Современная оболочка AI Council: чернильные поверхности, мятный акцент, плавающая навигация и контент от края до края на Android 11+. Сигналы — гипотезы, требующие контекста, а не автоматические вердикты. Версия `2.72.0` / versionCode `139` добавляет `UnderdeterminationPolicy`. Экранная `APP_VERSION` снова совпадает с Gradle (раньше на экране оставалась `2.70.0`).

AI Council — Android-приложение для работы с несколькими ИИ-провайдерами: независимые ответы, аудит, глубокий анализ, локальные серверы, поиск источников, импорт документов и экспорт отчётов.

## 2.72.0 — Недоопределённость

- Добавлен `UnderdeterminationPolicy`: локально замечает, когда одно объяснение объявляют единственно совместимым с наблюдениями («единственное возможное объяснение», «альтернативных механизмов нет», «the only possible explanation») без проверки соперничающего механизма.
- Отдельный сигнал, если оба эксперта закрывают альтернативы, хотя те же данные могут им соответствовать.
- Модуль подключён в `DeliberationSignals.detectAll`. Это гипотезы, требующие контекста, а не вердикт. Отличается от ложной дилеммы, апелляции к незнанию и narrative fallacy. Gradle / APP_VERSION теперь `2.72.0` / versionCode `139`.

## Примечания для static verify

- Ключи API в резервную копию **не включаются**.
- Импорт: **предпросмотр** перед вставкой, можно **редактировать** фрагмент.
- Для **сканированных PDF**: для каждой из **первых пяти страниц** сначала текстовый слой, затем OCR.
- В APК **не встроены веса языковой модели и on-device inference runtime**; локально — **Ollama/LM Studio**.
- **HTTP в LAN не шифрует трафик**; запросы идут **поисковым сервисам**.
- Режим «Только локальные ИИ» **не выключает веб-поиск**; **поисковая фраза отправляется внешним поисковым сервисам**.
