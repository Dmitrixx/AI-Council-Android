# AI Council Android — подготовленная версия 1.37.0

> **Статус репозитория:** в ветке main находятся README, план разработки и workflow импорта/сборки. Полные исходники приложения появятся здесь после импорта ZIP-архива. Пока в корне не появился каталог app/, репозиторий нельзя считать полной копией Android Studio-проекта.

## Последняя подготовленная версия — 1.37.0

К версии 1.37.0 добавлена локальная проверка текста перед передачей внешним ИИ: при обнаружении распространённых API-ключей, Bearer-токенов, credential-полей и других типичных секретов пользователь выбирает маскирование, осознанную отправку оригинала или отмену. В 1.36.0 также добавлены голосовой ввод с подтверждением, счётчик символов, приблизительная оценка токенов, показ/скрытие API-ключей, очистка черновика с подтверждением и доступные экранным дикторам статусы.

Ключевые ограничения: оценка токенов приблизительная; автоматический выбор стратегии основан на эвристиках; фильтрация секретов — best effort, а не абсолютная гарантия. APK версии 1.37.0 не следует считать проверенным, пока сборка GitHub Actions не завершится успешно и результат не будет скачан из артефактов.

## Сборка и импорт

Импорт настроен через файл .github/workflows/import-project-archive.yml. При добавлении одного архива с именем вида AI-Council-Android-vX.Y.Z-files.zip в корень main workflow проверяет архив, запускает доступные статические проверки и smoke-тесты, пытается собрать debug APK и прикрепляет APK вместе с SHA-256 к запуску GitHub Actions. После успешной сборки workflow коммитит распакованные исходники.

План дальнейшей работы: [ROADMAP_RU.md](ROADMAP_RU.md).

## Новое в 1.34.0 — дополнительная очистка секретов в API-ошибках

- Перед показом диагностического ответа провайдера приложение теперь очищает не только ключ, настроенный в этом профиле, но и распространённые форматы секретов: OpenAI-style `sk-…`, Google `AIza…`, Groq `gsk_…`, xAI `xai-…`, Hugging Face `hf_…`, GitHub tokens и AWS access key IDs.
- Маскируются значения в полях `api_key`, `access_token`, `client_secret`, `password`, `token`, заголовках `Authorization: Bearer …`, URL-параметрах ключей и блоках закрытых ключей.
- Очистка реализована отдельным `SecretRedactor`, используется форматтером HTTP-ошибок и покрыта автономными Java-тестами. Новых сторонних зависимостей и Android-разрешений не добавлено.
- Это best-effort фильтр текста ошибок, а не гарантия обнаружения любого неизвестного формата секрета; перед публикацией отчёта всё равно проверяйте текст.



## Новое в 1.33.0 — понятная диагностика API и отмена запросов

- При HTTP-ошибке AI Council показывает вероятную причину и следующее действие: проверьте ключ для 401, права доступа для 403, модель/URL для 404, квоту для 429 и размер задачи для 413.
- Ответ провайдера сохраняется как дополнительная подсказка, ограничивается 1200 символами и очищается от точно совпадающего API-ключа и распространённого Bearer-токена.
- Если пользователь останавливает запрос во время чтения ответа, приложение показывает отмену, а не путает её с неисправностью интернета.
- Тайм-аут, отмена и прерывание параллельного этапа получают отдельные сообщения.
- В проект добавлены 11 автономных проверок форматирования HTTP-ошибок.

## Интерфейс версии 1.32.0

- Минималистичная шапка: название приложения и компактный статус.
- Спокойная палитра: тёмный фон `#0E1116`, карточка `#171B22`, текст `#F2F4F7`, вторичный текст `#9AA3B2`, один основной акцент `#1F8A80`. Светлая палитра задаётся отдельными RGB-значениями.
- Режимы работы отображаются чипами с переносом на следующую строку при увеличенном масштабе текста.
- Импорт материалов и настройки веб-поиска открываются отдельными диалогами.
- Кнопка остановки показывается во время активной задачи вместо кнопки запуска.
- Нижняя навигация сокращена до «Штаб», «История», «Подключения» и переключает отдельные экраны вместо прокрутки одной длинной формы.
- Входная анимация сокращена до 200 мс и пропускается при отключённых системных анимациях.

Современное Android-приложение для совместной работы с несколькими ИИ: независимые мнения, проверка идей, глубокий анализ, интернет-поиск, импорт документов, локальный OCR, проекты и экспорт результатов.
