# AI Council 3.61.0

Интерфейс рабочего пространства обновлён: фирменный знак, согласованная типографика, состояния фокуса и доступные сенсорные зоны. Выбранный режим восстанавливается после перезапуска, а статусы и прогресс доступны TalkBack.

Добавлена локальная адаптация стратегии по явной оценке результата. Пользователь оценивает полезность формата ответа; приложение сохраняет только агрегированные счётчики по шести типам задач и четырём стратегиям. Минимум четыре оценки, сглаживание Beta(2,2), ограничение и затухание счётчиков уменьшают влияние случайных нажатий. Авто-режим может выбрать другую стратегию только при устойчивом преимуществе и наличии нужных провайдеров. Ручной выбор, фильтр бесплатных провайдеров и минимальный уровень проверки для рискованных тем сохраняются. Тексты задач, ответы, API-ключи и данные моделей в профиль не записываются. Память можно сбросить в настройках.

Полный исходный код `MainActivity.java` хранится в Git. CI не скачивает скрытый снимок исходника: неполный файл приводит к явной ошибке. Версия: `3.61.0` / versionCode `229`.

Локальная проверка эффекта компромисса теперь отмечает вердикт, который принимает средний вариант за решающий только потому что он компромисс между крайностями, без абсолютной ценности по ключевым измерениям или независимого сравнения. Назвать пробел — не ошибка. Координатор не закрывает вопрос одной позицией «середина». Версия на экране совпадает с Gradle: `3.53.0` / versionCode `220`.
