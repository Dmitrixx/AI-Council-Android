# AI Council 2.77.0

В локальной карте 2.77.0 отвержение совета потому что он звучит как принуждение остаётся гипотезой (reactance), а не вердиктом. В 2.76.0 отвержение данных из-за конфликта с парадигмой — тоже гипотеза (semmelweis reflex). Сигналы требуют контекста.

Современная оболочка AI Council: чернильные поверхности, мятный акцент, плавающая навигация и контент от края до края на Android 11+. Версия `2.77.0` / versionCode `144` добавляет `ReactancePolicy`.

AI Council — Android-приложение для работы с несколькими ИИ-провайдерами: независимые ответы, аудит, глубокий анализ, локальные серверы, поиск источников, импорт документов и экспорт отчётов.

## 2.77.0 — Reactance

- Добавлен `ReactancePolicy`: локально замечает отвержение рекомендации потому что она звучит как принуждение или ограничение свободы («заставляют», «нет выбора», «forced»), без оценки по существу.
- Отдельный сигнал, если оба эксперта отвергают вариант из-за ощущения принуждения.
- Модуль подключён в `DeliberationSignals.detectAll`. Это гипотезы, требующие контекста, а не вердикт. Отличается от reactive devaluation, status-quo, action bias и authority bias. Gradle / APP_VERSION: `2.77.0` / versionCode `144`.

## 2.76.0 — Semmelweis reflex

- Добавлен `SemmelweisReflexPolicy`: локально замечает отвержение наблюдения / данных потому что они противоречат устоявшейся парадигме, без независимой оценки самих данных.
- Отдельный сигнал, если оба эксперта отбрасывают disconfirming evidence из-за конфликта с принятой моделью.

## 2.75.0 — Журнал допущений

- Добавлен `AssumptionLedgerPolicy`: рекомендация без названного допущения и без наблюдения, которое её отменит, остаётся гипотезой.
- Отдельный сигнал при противоположных несущих допущениях у двух экспертов.

## Примечания для static verify

- Ключи API в резервную копию **не включаются**.
- Импорт: **предпросмотр** перед вставкой, можно **редактировать** фрагмент.
- Для **сканированных PDF**: для каждой из **первых пяти страниц** сначала текстовый слой, затем OCR.
- В APК **не встроены веса языковой модели и on-device inference runtime**; локально — **Ollama/LM Studio**.
- **HTTP в LAN не шифрует трафик**; запросы идут **поисковым сервисам**.
- Режим «Только локальные ИИ» **не выключает веб-поиск**; **поисковая фраза отправляется внешним поисковым сервисам**.
