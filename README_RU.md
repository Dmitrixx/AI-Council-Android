# AI Council 2.4.2

Современная оболочка 2.1.0: чернильные поверхности, мятный акцент, плавающая навигация и контент от края до края на Android 11+. Debug APK собирается в GitHub Actions и публикуется в Releases.

Мульти-провайдерный AI-совет для Android — независимые ответы, аудиты, глубокий анализ, локальные серверы, поиск источников, импорт документов и экспорт отчётов.

## Что делает

Один промпт → структурированное обсуждение до трёх экспертов (провайдеры и роли настраиваются).

| Режим | Поведение |
| --- | --- |
| ⚡ Быстрый ответ | Один эксперт |
| 🤝 Совет | Три независимых ответа + координатор |
| 🛡 Аудит | Два эксперта + критический разбор |
| 🔬 Глубокий анализ | Многораундовая критика и уточнение |
| 🤖 Авто | Эвристический роутинг (RU / UK / EN) |

## Сборка

```bash
git clone https://github.com/Dmitrixx/AI-Council-Android.git
cd AI-Council-Android
./gradlew assembleDebug
```

Требуется JDK 21 и Android SDK 36.
