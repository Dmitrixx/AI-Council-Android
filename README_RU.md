# AI Council 3.70.0

Локальная проверка неблагоприятного отбора теперь отмечает вердикт, который считает добровольно вошедших в предложение, страховку, кредит или программу типичным пулом, не спрашивая, не смещает ли скрытая информация эту сторону против контрагента. Это скрытый тип до контракта, а не смена поведения после защиты. Назвать пробел — не ошибка. Координатор не закрывает вопрос только потому, что добровольцы похожи на среднего клиента. Версия совпадает с Gradle: `3.70.0` / versionCode `238`.

# AI Council 3.65.0

Локальная проверка ожидаемого сожаления теперь отмечает вердикт, который принимает избегание возможного будущего сожаления за решающее для выбора более безопасного, статус-кво или «хотя бы попробовал» варианта, без оценки ожидаемой ценности альтернатив, вероятности исхода, вызывающего сожаление, или того, что сожаление — эмоциональная стоимость, которую нужно взвесить. Назвать пробел — не ошибка. Координатор не закрывает вопрос только на ожидаемом сожалении. Версия совпадает с Gradle: `3.65.0` / versionCode `233`.

# AI Council 3.64.0

Локальная проверка найтовской неопределённости теперь отмечает вердикт, который трактует решение под подлинной неопределённостью как задачу риска с известными вероятностями, без признания различия или рассмотрения робастных подходов. Назвать пробел — не ошибка. Координатор не закрывает вопрос присвоением точных вероятностей неизвестным неизвестным. Версия совпадает с Gradle: `3.64.0` / versionCode `232`.
