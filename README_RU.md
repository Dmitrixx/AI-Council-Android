# AI Council 3.10.0

Локальная проверка appeal-to-force / аргумента от силы теперь отмечает выводы, что что-то истинно или должно быть принято лишь потому, что есть угроза силы, наказания или принуждения. Назвать ошибку — не ошибка. Координатор не закрывает вердикт на одной угрозе силы. Эксперты получают то же правило в общей базе промпта. Версия на экране совпадает с Gradle: `3.10.0` / versionCode `177`.

# AI Council 3.8.0

Локальная проверка composition/division теперь отмечает выводы, которые приписывают свойство частей целому (или целого частям) лишь потому, что оно верно для одного без независимого основания для emergence или reduction. Назвать ошибку — не ошибка. Координатор не закрывает вердикт на одном composition/division. Эксперты получают то же правило в общей базе промпта. Версия на экране совпадает с Gradle: `3.8.0` / versionCode `175`.
