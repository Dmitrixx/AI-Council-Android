# AI Council 2.79.0

В локальной карте 2.79.0 атака на человека вместо разбора сути аргумента остаётся гипотезой (ad hominem), а не вердиктом. В 2.78.0 утверждение о неизбежном скользком склоне без обоснования цепочки — тоже гипотеза (slippery slope). Сигналы требуют контекста.

Современная оболочка AI Council: чернильные поверхности, мятный акцент, плавающая навигация и контент от края до края на Android 11+. Версия `2.79.0` / versionCode `146` добавляет `AdHominemPolicy`.

AI Council — Android-приложение для работы с несколькими ИИ-провайдерами: независимые ответы, аудит, глубокий анализ, локальные серверы, поиск источников, импорт документов и экспорт отчётов.

## 2.79.0 — Ad hominem

- Добавлен `AdHominemPolicy`: локально замечает, когда позиция отвергается через атаку на человека (мотив, характер, «ты такой-то, поэтому аргумент неверен») вместо разбора сути утверждения.
- Отдельный сигнал, если оба эксперта отвергают позицию через личные нападки.
- Модуль подключён в `DeliberationSignals.detectAll`. Это гипотезы, требующие контекста, а не вердикт. Отличается от authority bias, reactive devaluation и straw man. Gradle / APP_VERSION: `2.79.0` / versionCode `146`.

## 2.78.0 — Slippery slope

- Добавлен `SlipperySlopePolicy`: локально замечает, когда скромный шаг без обоснования промежуточных звеньев и вероятностей объявляется неизбежным путём к экстремуму («если разрешим это, то дальше…»).
- Отдельный сигнал, если оба эксперта отвергают вариант из-за неуточнённого скользкого склона.
- Модуль подключён в `DeliberationSignals.detectAll`. Это гипотезы, требующие контекста, а не вердикт. Отличается от false dilemma и normalcy bias. Gradle / APP_VERSION: `2.78.0` / versionCode `145`.

## 2.77.0 — Reactance

- Добавлен `ReactancePolicy`: локально замечает отвержение рекомендации потому что она звучит как принуждение или ограничение свободы («заставляют», «нет выбора», «forced»), без оценки по существу.
- Отдельный сигнал, если оба эксперта отвергают вариант из-за ощущения принуждения.

## 2.76.0 — Semmelweis reflex

- Добавлен `SemmelweisReflexPolicy`: локально замечает отвержение наблюдения / данных потому что они противоречат устоявшейся парадигме, без независимой оценки самих данных.
- Отдельный сигнал, если оба эксперта отбрасывают disconfirming evidence из-за конфликта с принятой моделью.

## Примечания для static verify

- Ключи API в резервную копию **не включаются**.
- Импорт: **предпросмотр** перед вставкой, можно **редактировать** фрагмент.
- Для **сканированных PDF**: для каждой из **первых пяти страниц** сначала текстовый слой, затем OCR.
- В APK **не встроены веса языковой модели и on-device inference runtime**; локально — **Ollama/LM Studio**.
- **HTTP в LAN не шифрует трафик**; запросы идут **поисковым сервисам**.
- Режим «Только локальные ИИ» **не выключает веб-поиск**; **поисковая фраза отправляется внешним поисковым сервисам**.
