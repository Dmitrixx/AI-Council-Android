# AI Council 2.76.0

В локальной карте 2.76.0 отвержение новых данных потому что они противоречат устоявшейся парадигме остаётся гипотезой (semmelweis reflex), а не вердиктом. В 2.75.0 рекомендация без названного допущения и без наблюдения, которое её отменит, тоже остаётся гипотезой. Сигналы — гипотезы, требующие контекста.

Современная оболочка AI Council: чернильные поверхности, мятный акцент, плавающая навигация и контент от края до края на Android 11+. Версия `2.76.0` / versionCode `143` добавляет `SemmelweisReflexPolicy`.

AI Council — Android-приложение для работы с несколькими ИИ-провайдерами: независимые ответы, аудит, глубокий анализ, локальные серверы, поиск источников, импорт документов и экспорт отчётов.

## 2.76.0 — Semmelweis reflex

- Добавлен `SemmelweisReflexPolicy`: локально замечает отвержение наблюдения / данных потому что они противоречат устоявшейся парадигме или «как принято в области», без независимой оценки самих данных.
- Отдельный сигнал, если оба эксперта отбрасывают disconfirming evidence из-за конфликта с принятой моделью.
- Модуль подключён в `DeliberationSignals.detectAll`. Это гипотезы, требующие контекста, а не вердикт. Отличается от confirmation bias, reactive devaluation, straw man и status-quo bias. Gradle / APP_VERSION: `2.76.0` / versionCode `143`.

## 2.75.0 — Журнал допущений

- Добавлен `AssumptionLedgerPolicy`: локально замечает рекомендацию, которая не называет несущее допущение и не называет наблюдение, способное её отменить.
- Отдельный сигнал, если два ответа стоят на противоположных допущениях об одном и том же.
- Модуль подключён в `DeliberationSignals.detectAll`. Протокол синтеза просит строку «Допущение: …».

## Примечания для static verify

- Ключи API в резервную копию **не включаются**.
- Импорт: **предпросмотр** перед вставкой, можно **редактировать** фрагмент.
- Для **сканированных PDF**: для каждой из **первых пяти страниц** сначала текстовый слой, затем OCR.
- В APК **не встроены веса языковой модели и on-device inference runtime**; локально — **Ollama/LM Studio**.
- **HTTP в LAN не шифрует трафик**; запросы идут **поисковым сервисам**.
- Режим «Только локальные ИИ» **не выключает веб-поиск**; **поисковая фраза отправляется внешним поисковым сервисам**.
