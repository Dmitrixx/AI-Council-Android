# AI Council 3.61.0

Совет больше не считает повтор общего текста второй независимой выборкой. Скрытый профиль: вердикт закрывается фразой «все согласны», а замер или факт, который есть только у одной стороны, остаётся без ответа. Процитировать этот факт или сказать, что согласие не доказательство, — не ошибка. Версия совпадает с Gradle: `3.61.0` / versionCode `229`.

# AI Council 3.60.0

Локальный диагноз разногласия больше не даёт координатору усреднять несовместимые причины. Хрупкое согласие: оба эксперта выбирают одно и то же по разным механизмам и не называют наблюдение, которое переключит вывод. Факт против нормы: одна сторона закрывает оценку, другая — долженствование; это не две оценки одного числа. Назвать этот раскол — не ошибка. Версия совпадает с Gradle: `3.60.0` / versionCode `228`.

# AI Council 3.59.1

Координатор получает приоритетную карту локальных сигналов: гипотезы сортируются по влиянию на решение, дубликаты убираются, а пользователю показываются не более четырёх конкретных проверок. Неизвестные числовые разногласия не выдаются за логические ошибки. Исправлены девять регрессионных smoke-тестов и координата AndroidX Test Rules. Версия совпадает с Gradle: `3.59.1` / versionCode `227`.
