# AI Council 3.11.0

Локальная проверка loaded-question / нагруженного (сложного) вопроса теперь отмечает выводы, которые опираются на вопрос, уже предполагающий недоказанный или спорный тезис. Назвать ошибку — не ошибка. Координатор не закрывает вердикт на одном нагруженном вопросе. Эксперты получают то же правило в общей базе промпта. Версия на экране совпадает с Gradle: `3.11.0` / versionCode `178`.

# AI Council 3.10.0

Локальная проверка appeal-to-force / аргумента от силы теперь отмечает выводы, что что-то истинно или должно быть принято лишь потому, что есть угроза силы, наказания или принуждения. Назвать ошибку — не ошибка. Координатор не закрывает вердикт на одной угрозе силы. Эксперты получают то же правило в общей базе промпта. Версия на экране совпадает с Gradle: `3.10.0` / versionCode `177`.
