# AI Council 3.92.0

Кадр решения получил два новых закрываемых пробела для задач-решений: альтернативная стоимость (от чего отказываются / следующий лучший вариант) и pre-mortem / критерий отмены (режим отказа + условие остановки). Бинарные формулировки вида «стоит ли X?» / «should we X?» теперь извлекают действие и «оставить как есть» как две живые альтернативы. Локальная проверка показывает усиленный кадр без сети. Вердикт, который всё равно закрывает выбор при открытом верхнем пробеле, — только гипотеза. Назвать пробел — не ошибка. Версия совпадает с Gradle: `3.92.0` / versionCode `260`.

# AI Council 3.91.0

Локальный кадр решения теперь считается из текста вопроса до того, как заговорит любая модель. Он называет сам вопрос, достаёт явные альтернативы и величины и перечисляет, чего не хватает, чтобы выбор можно было закрыть: варианты (включая «оставить как есть»), масштаб ставки, горизонт, кто несёт убыток, базовая частота и критерий успеха. Этот кадр уходит экспертам, а локальная проверка показывает его без сети. Вердикт, который всё равно закрывает выбор при открытом верхнем пробеле, — только гипотеза. Назвать пробел — не ошибка. Сигналы ключевых допущений и пороговых эффектов теперь тоже доходят до координатора: раньше он их пропускал. Версия совпадает с Gradle: `3.91.0` / versionCode `259`.

# AI Council 3.90.0

Локальная проверка порогов / tipping-point / фазового перехода теперь отмечает вердикт, который трактует эффекты как непрерывные и линейные через существенный порог (точка перелома, регуляторный обрыв, критическая масса сети, фазовый переход) без указания положения порога и характера разрыва. Назвать пробел — не ошибка. Координатор не закрывает вопрос только на плавной экстраполяции, когда решение может пересечь нелинейную границу. Отдельно от interaction-effects и marginal-analysis. Версия совпадает с Gradle: `3.90.0` / versionCode `258`.

# AI Council 3.89.0

Локальная проверка эффектов взаимодействия / неаддитивности теперь отмечает вердикт, который трактует пакет одновременных действий или комбинированных вмешательств как простую сумму отдельных эффектов без указания членов взаимодействия, синергий, помех, порогов или почему эффекты остаются приблизительно аддитивными. Назвать пробел — не ошибка. Координатор не закрывает вопрос только на аддитивном разложении, когда решение объединяет несколько рычагов или пересекает порог, где взаимодействия становятся существенными. Версия совпадает с Gradle: `3.89.0` / versionCode `257`.
