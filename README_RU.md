# AI Council 3.83.0

Локальная проверка множественных сравнений / look-elsewhere теперь отмечает вердикт, который закрывает выбор на статистически значимом результате, p-value или «доказано», не упоминая число тестов, family-wise error, look-elsewhere effect или сад расходящихся путей. Назвать пробел — не ошибка. Координатор не закрывает вопрос только на нескорректированной значимости. Версия совпадает с Gradle: `3.83.0` / versionCode `251`.

# AI Council 3.82.0

Совет получил три приёма, которых не хватало для умного закрытия выбора, и два уже написанных сигнала наконец доходят до координатора. Проверка стального человека отмечает вердикт, который бьёт карикатуру чужой позиции и не формулирует её сильнейшую честную версию. Инверсия отмечает план, где сказано только что делать, но не как это провалится и чего избежать. Разложение Ферми отмечает точную цифру, которую подают как измерение, не разложив на оцениваемые множители. `AbsoluteRiskNeglectPolicy` подключён в `DeliberationSignals.detectAll`: раньше файл существовал, вызова не было. Координатор превращает абсолютный риск и мотивированное рассуждение в инструкции, а не теряет их. Назвать пробел — не ошибка. Версия совпадает с Gradle: `3.82.0` / versionCode `250`.

# AI Council 3.79.0

Локальная проверка коллайдера / парадокса Берксона теперь отмечает вердикт, который принимает связь, увиденную только внутри отобранной группы — поступивших, госпитализированных, выживших или ответивших, — за связь во всей популяции, не спрашивая, не создал ли сам отбор эту корреляцию. Назвать пробел — не ошибка. Координатор также превращает в инструкции уже находимые гипотезы (малая выборка, «в этот раз иначе», сложность, найтовская неопределённость, ожидаемое сожаление, Симпсон, Гудхарт, эргодичность, коллайдер), а не молча их теряет. Версия совпадает с Gradle: `3.79.0` / versionCode `247`.
