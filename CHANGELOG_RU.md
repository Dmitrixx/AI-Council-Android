# Продолжение разработки 2.0.0 — гибридный PDF: текстовый слой плюс OCR

- PDF-импорт теперь обрабатывает страницы единым процессором: PDFBox сначала извлекает текстовый слой каждой страницы, а Android `PdfRenderer` рендерит только страницы, в которых не найден текст. OCR выполняется только для этих страниц.
- Обычный путь импорта PDF и отдельный путь OCR с выбором русского/украинского языка используют один процессор; текстовые PDF больше не требуют ненужного запуска OCR, а смешанные документы не теряют сканированные страницы.
- Предпросмотр маркирует источник каждой страницы (текстовый слой или OCR), отмечает страницы без распознанного текста и показывает предупреждения. Изображения/PDF не отправляются в сеть; загрузчик языковой модели вызывается только при фактической необходимости кириллического OCR.
- Добавлен smoke integration test, проверяющий, что страница с извлекаемым текстом использует PDFBox и не запускает OCR. `OcrInputPolicySmokeTest` теперь 18/18, `OcrDocumentProcessorSmokeTest` — 5/5.
- `tools/verify_project.py` — 278/278, `tools/desktop_smoke/run.sh` — 362/362. Desktop-тест использует API-shape stubs для Android/PDFBox/ML Kit/Tesseract; реальная Gradle-сборка и тестирование на устройстве всё ещё не выполнены.

# Продолжение разработки 2.0.0 — сетевой поиск вынесен из MainActivity

- Оркестрация Brave Search, Tavily, Wikipedia/MediaWiki и DuckDuckGo Instant Answer JSON перенесена в `WebSearchService`. В `MainActivity` остался тонкий адаптер, который передаёт уже очищенный запрос, выбор контекста, зашифрованные/расшифрованные в Activity ключи и статусный callback.

- `WebSearchServiceSmokeTest` добавлен: 5/5 проверок конверсии HTML в текст, исключения активного содержимого, пустого запроса и ранней отмены без сетевого вызова.

## 1.36.0 — 2026-10-20

### Более понятный размер задач
- Добавлен автономный `PromptMetricsPolicy`: приблизительно оценивает число токенов по Unicode-категориям и даёт только грубую метку размера запроса.

### Голос и доступность
- Если системное распознавание речи возвращает несколько вариантов, приложение показывает уникальные альтернативы на выбор, сохраняя порядок ранжирования службы распознавания.

- Добавлена настройка необязательного Brave Search токена. Он хранится зашифрованным через Android Keystore и отправляется только сервису Brave.
- Сниппеты помечаются названием поискового источника и HTTPS-ссылкой; системная инструкция по-прежнему рассматривает веб-материалы как недоверенные данные.

### Локальные модели
- Добавлены пресеты Ollama и LM Studio для OpenAI-совместимых `/v1/chat/completions` endpoints.
- HTTP разрешён только для loopback, `.local` и приватных IPv4-адресов; облачные endpoints должны использовать HTTPS.
- Локальный сервер может работать без API-ключа; для таких запросов заголовок `Authorization` не отправляется.
- Добавлен режим «Только локальные ИИ», который блокирует запуск, follow-up и тест подключения, если необходимый endpoint не локальный.
- Добавлены чистые Java классы политики URL и поисковых запросов с desktop smoke tests.

### Ограничения
- В APK не встроен самостоятельный движок LLM и не включены веса модели. Инференс выполняет выбранный сервер Ollama/LM Studio; это не является встроенным on-device inference.
- Веб-поиск зависит от доступности внешних сервисов. Без Brave API токена Wikipedia Search и DuckDuckGo Instant Answer могут дать узкий набор материалов.
- HTTP в LAN не шифрует трафик; требуется доверенная сеть либо HTTPS reverse proxy.
- Gradle/Android SDK недоступны в текущей среде, поэтому APK и runtime-интеграция не собраны/не проверены на устройстве.
