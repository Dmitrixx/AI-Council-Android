# 3.60.0 — обновление интерфейса и воспроизводимости сборки

- Основной экран получил фирменный знак AI Council, более последовательную типографику и единые пропорции карточек; для полей ввода добавлено заметное состояние клавиатурного фокуса.
- Увеличены зоны нажатия инструментов импорта, веб-поиска и голосового ввода. Выбранный режим совета теперь восстанавливается из настроек и использует контрастный цвет текста в обеих темах.
- Полный `MainActivity.java` сохранён непосредственно в Git-репозитории. Сценарий подготовки больше не скачивает скрытый исходный снимок: неполный UI-код останавливает сборку с понятной ошибкой.
- Исправлена компиляция Android UI smoke-теста (`throws Throwable`) и добавлены проверки логотипа, статуса, прогресса и выбранного режима.
- Версия приложения синхронизирована: `3.60.0` / versionCode `228`.

# 3.59.1 — приоритетные подсказки координатору и восстановление CI

- `CoordinatorCue` теперь преобразует распознанные локальные сигналы в короткие проверяемые действия: сначала показывает риски, способные сильнее повлиять на решение, удаляет дубликаты и ограничивает вывод четырьмя пунктами. Неизвестные конфликты чисел не маскируются под логические ошибки.
- Для каждого сигнала явно сохраняется статус гипотезы, требующей контекста. Координатору предлагается проверить абсолютный риск, базовую частоту, первоисточник, нормативную посылку, альтернативную стоимость и другие конкретные основания, а не принимать локальный сигнал за вердикт.
- Исправлены девять регрессионных smoke-тестов, ранее блокировавших APK-сборку. Исправлена координата AndroidX Test Rules: `androidx.test:rules:1.6.1`.
- Версия приложения синхронизирована: `3.59.1` / versionCode `227`.

# 3.59.0 — прошлые вложения не закрывают продолжение провального курса

- `EscalationOfCommitmentPolicy`: локально замечает вердикт, который принимает продолжение провального проекта или курса за решающее только из-за уже вложенных затрат или предыдущих обязательств, без оценки будущей ценности, альтернативной стоимости продолжения или критериев остановки. Назвать этот пробел — не ошибка.
- Модуль подключён в `DeliberationSignals.detectAll`. Координатор не закрывает вопрос одними прошлыми вложениями. Это гипотеза, требующая контекста, а не вердикт.
- Версия на экране синхронизирована с Gradle: `3.59.0` / versionCode `226`.
