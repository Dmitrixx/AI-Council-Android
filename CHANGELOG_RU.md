# 3.65.0 — ожидаемое сожаление не закрывает выбор

- `AnticipatedRegretPolicy`: локально замечает вердикт, который принимает избегание возможного будущего сожаления за решающее для выбора более безопасного, статус-кво или «хотя бы попробовал» варианта, без оценки ожидаемой ценности альтернатив, вероятности исхода, вызывающего сожаление, или того, что сожаление — эмоциональная стоимость, которую нужно взвесить, а не единственный критерий. Назвать пробел — не ошибка.
- Модуль подключён в `DeliberationSignals.detectAll`. Координатор не закрывает вопрос только на ожидаемом сожалении. Это гипотеза, требующая контекста, а не вердикт.
- Версия на экране синхронизирована с Gradle: `3.65.0` / versionCode `233`.

# 3.64.0 — найтовская неопределённость

- `KnightianUncertaintyPolicy`: локально замечает вердикт, который трактует решение под подлинной неопределённостью (неизвестные вероятности, немоделируемые риски, unknown unknowns) как задачу риска с известными вероятностями, без признания различия или рассмотрения робастных / maximin / сценарных подходов. Назвать пробел — не ошибка.
- Модуль подключён в `DeliberationSignals.detectAll`. Координатор не закрывает вопрос присвоением точных вероятностей неизвестным неизвестным.
- Версия совпадает с Gradle: `3.64.0` / versionCode `232`.
