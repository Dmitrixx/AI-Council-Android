# 3.73.0 — видимые успехи не вся выборка

- `SurvivorshipBiasPolicy`: локально замечает вердикт, который строит вывод на видимых успехах, «тех, кто добился» или историях победителей, без учёта невидимых провалов, доли отсева или базовой частоты неудач в том же классе. Назвать пробел — не ошибка.
- Модуль уже был подключён в `DeliberationSignals.detectAll`; теперь добавлен в обязательные политики и в подсказку координатора. Координатор не закрывает выбор только на видимых успехах. Это гипотеза, требующая контекста, а не вердикт.
- Версия совпадает с Gradle: `3.73.0` / versionCode `241`.

# 3.72.0 — метка «делать» больше не закрывает пустой вердикт

- `VerdictClosurePolicy`: локально проверяет уже поставленную метку, а не только черновики экспертов. `ДЕЛАТЬ` / `НЕ ДЕЛАТЬ` без наблюдения, которое перевернёт вывод, и без пометки обратимости — совет не закрыт. Голая метка `СНАЧАЛА ПРОВЕРИТЬ` без конкретной проверки тоже не закрывает. Прогноз одной точкой без диапазона и reference class не закрывает оценку. Назвать пробел — не ошибка. «Сделать» и другие слова на `-делать` меткой не считаются.
- Проверка висит на итоге координатора (`footer`) и на паре ответов в `DeliberationSignals.detectAll`. Координатор получает короткое напоминание до выбора метки. Это гипотеза о полноте, не запрет рекомендации.
- Версия совпадает с Gradle: `3.72.0` / versionCode `240`.

# 3.68.0 — катастрофический / асимметричный downside не закрывается средней ожидаемой ценностью

- `CatastrophicRiskPolicy`: локально замечает вердикт, который закрывает высокоставочное решение по обычной ожидаемой ценности, когда downside тяжёлый, необратимый или потенциально разорительный, без явного взвешивания величины наихудшего правдоподобного исхода или страховок от fat tail / ruin. Назвать пробел — не ошибка.
- Модуль подключён в `DeliberationSignals.detectAll`. Координатор не закрывает вопрос только на средней ожидаемой ценности при асимметричном тяжёлом хвосте. Это гипотеза, требующая контекста, а не вердикт.
- Версия совпадает с Gradle: `3.68.0` / versionCode `236`.
