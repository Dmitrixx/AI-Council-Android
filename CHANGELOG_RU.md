# 2.41.0 — Simpson paradox

- Добавлен `SimpsonParadoxPolicy`. Вывод «в целом / по всей выборке, значит в каждой группе» без проверки, не разворачивается ли связь при стратификации, — гипотеза, не доказательство.
- Отдельный сигнал, если оба эксперта переносят агрегированный тренд на подгруппы и не называют разбиение.
- `SynthesisProtocol` для решений просит не переносить общий тренд на подгруппы. Координатор не закрывает метку таким сигналом.
- Модуль подключён в `DeliberationSignals.detectAll`. В прогон desktop smoke добавлены политика и четыре предыдущих детектора, без которых `DeliberationSignals` не компилировался. Сигналы — гипотезы, требующие контекста. Gradle теперь `2.41.0` / versionCode `108`.

# 2.40.0 — Base rate neglect

- Добавлен `BaseRateNeglectPolicy`. Вывод из яркого случая, сходства или малой выборки без учёта базовой частоты популяции / prior — гипотеза, не доказательство.
- Отдельный сигнал, если оба эксперта опираются на репрезентативность без называния base rate класса.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.40.0` / versionCode `107`.

# 2.39.0 — Appeal to ignorance

- Добавлен `AppealToIgnorancePolicy`. Вывод из «никто не опроверг обратное» или отсутствия доказательств без позитивного основания и явного бремени доказательства — гипотеза, не доказательство.
- Отдельный сигнал, если оба эксперта закрывают вывод тем, что оппонент не доказал обратное.
- `SynthesisProtocol` для решений просит не закрывать вывод отсутствием доказательств обратного. Координатор не закрывает метку таким сигналом.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.39.0` / versionCode `106`.

# 2.38.0 — Selection bias

- Добавлен `SelectionBiasPolicy`. Вывод из удобной, самоотобранной или усечённой выборки без учёта процесса отбора и base rate популяции — гипотеза, не доказательство.
- Отдельный сигнал, если оба эксперта опираются на отобранную выборку и не называют, кто не попал в наблюдение.
- `SynthesisProtocol` для решений просит учитывать отбор выборки. Координатор не закрывает метку выводом из нерепрезентативной выборки.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.38.0` / versionCode `105`.

# 2.94.0 — Narrative fallacy

- Добавлен `NarrativeFallacyPolicy`. Связная, яркая история не сильнее base rate, статистики и «грязных» данных.
- Отдельный сигнал, если оба эксперта закрывают вывод сюжетом вместо частоты класса.
- Развилка «история доказывает» против явной опоры на base rate / reference class не усредняется.
- Обычный пример из практики и названное разделение «история ≠ статистика» сигнал не поднимают.
- `SynthesisProtocol` для решений запрещает закрывать выбор историей вместо base rate. Координатор не переводит narrative fallacy в ДЕЛАТЬ или НЕ ДЕЛАТЬ.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION остаются 2.36.0 / versionCode 103 согласно CI.
