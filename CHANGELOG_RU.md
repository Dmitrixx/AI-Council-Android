# 3.84.0 — сильная рекомендация без ключевых допущений не закрывает выбор

- `KeyAssumptionsPolicy`: локально замечает вердикт, который рекомендует действие как ясно лучшее, не называя ключевые предпосылки (о затратах, вероятностях, реакциях агентов, внешних условиях, валидности модели или качестве данных), от которых оно зависит. Назвать пробел — не ошибка.
- Модуль подключён в `DeliberationSignals.detectAll`. Координатор получает инструкцию не закрывать вопрос только на рекомендации, скрывающей несущие допущения. Это гипотеза, требующая контекста, а не вердикт.
- Версия совпадает с Gradle: `3.84.0` / versionCode `252`.

# 3.83.0 — значимый результат без поправки на множественные сравнения не закрывает выбор

- `MultipleComparisonsPolicy`: локально замечает вердикт, который закрывает выбор на статистически значимом результате, p-value или «доказано», не упоминая число тестов, family-wise error, look-elsewhere effect или сад расходящихся путей. Назвать пробел — не ошибка.
- Модуль подключён в `DeliberationSignals.detectAll`. Координатор получает инструкцию не закрывать вопрос только на нескорректированной значимости. Это гипотеза, требующая контекста, а не вердикт.
- Версия совпадает с Gradle: `3.83.0` / versionCode `251`.

# 3.82.0 — стальной человек, инверсия и Ферми; забытые сигналы доходят до координатора

- `SteelmanPolicy`: локально замечает вердикт, который отвергает чужую позицию через слабую карикатуру, не сформулировав сильнейшую честную версию. Назвать пробел — не ошибка.
- `InversionPolicy`: план «только что делать» без сценария провала и без того, чего избежать, не закрывает выбор.
- `FermiDecompositionPolicy`: точное число без разложения на оцениваемые множители — не измерение.
- `AbsoluteRiskNeglectPolicy` подключён в `DeliberationSignals.detectAll` (файл был, вызова не было). Координатор получает инструкции и по абсолютному риску, и по мотивированному рассуждению.
- Протокол решения для экспертов и координатора требует эти три приёма до метки ДЕЛАТЬ / НЕ ДЕЛАТЬ.
- Версия совпадает с Gradle: `3.82.0` / versionCode `250`.

# 3.81.0 — относительный процент не закрывает выбор без абсолютного риска

- `AbsoluteRiskNeglectPolicy`: локально замечает вердикт, который закрывает выбор на относительном снижении риска, процентном улучшении или отношении, без указания абсолютного риска, базовой частоты или NNT. Назвать пробел — не ошибка.
- Модуль подключён в `DeliberationSignals.detectAll`. Координатор не закрывает вопрос только на относительных показателях. Это гипотеза, требующая контекста, а не вердикт.
- Версия совпадает с Gradle: `3.81.0` / versionCode `249`.
