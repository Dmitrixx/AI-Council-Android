# 2.90.0 — Texas sharpshooter / post-hoc target fitting

- Добавлен `TexasSharpshooterPolicy`. Когда вывод делается на основе цели, подогнанной под наблюдённый кластер после факта («подогнал цель под данные», «выбрал кластер после наблюдения», «texas sharpshooter», «drew the target after») — гипотеза, не независимое основание (texas sharpshooter / post-hoc target fitting).
- Отдельный сигнал, если оба эксперта подгоняют цель под данные.
- Модуль подключён в `DeliberationSignals.detectAll`. Координатор не закрывает вердикт на основании пост-фактум подогнанной цели. Упоминание самой ошибки или «подгон цели не доказательство» сигнал не включает. Сигналы — гипотезы, требующие контекста. Экранная `APP_VERSION` совпадает с Gradle: `2.90.0` / versionCode `157`.

# 2.89.0 — Cherry-picking / selective evidence

- Добавлен `CherryPickingPolicy`. Когда вывод делается на основе тщательно подобранных поддерживающих данных при игнорировании противоречащих («все исследования подтверждают», «выбрал только удобные», «cherry-picked», «only the favorable data») — гипотеза, не независимое основание (cherry-picking / selective evidence).
- Отдельный сигнал, если оба эксперта опираются на выборочные данные.
- Модуль подключён в `DeliberationSignals.detectAll`. Координатор не закрывает вердикт на основании селективной выборки. Упоминание самой ошибки или «выборочные данные не доказательство» сигнал не включает. Сигналы — гипотезы, требующие контекста. Экранная `APP_VERSION` совпадает с Gradle: `2.89.0` / versionCode `156`.

# 2.88.0 — Hasty generalization

- Добавлен `HastyGeneralizationPolicy`. Когда широкий вывод делается из одного или нескольких нерепрезентативных случаев («один пример доказывает», «все кого я знаю», «from this single case», «one example proves») — гипотеза, не независимое основание (hasty generalization / insufficient sample).
- Отдельный сигнал, если оба эксперта обобщают по маленькой выборке.
- Модуль подключён в `DeliberationSignals.detectAll`. Координатор не закрывает вердикт на основании недостаточной выборки. Упоминание самой ошибки или «один пример не доказательство» сигнал не включает. Сигналы — гипотезы, требующие контекста. Экранная `APP_VERSION` совпадает с Gradle: `2.88.0` / versionCode `155`.
