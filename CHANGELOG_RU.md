# 2.59.0 — Automation bias

- Добавлен `AutomationBiasPolicy`. Вывод, что рекомендация верна потому что её дала AI/алгоритм/модель, без независимой проверки или признания ограничений автоматизации — гипотеза, не доказательство (automation bias).
- Отдельный сигнал, если оба эксперта принимают рекомендацию только потому что её подтвердила AI/модель, без калибровки на неавтоматические источники.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.59.0` / versionCode `126`.

# 2.58.0 — Just-world bias

- Добавлен `JustWorldBiasPolicy`. Вывод, что исход доказывает заслуженность (люди получают по заслугам, жертва сама виновата, «всё не зря») без учёта случайности, системных факторов или удачи — гипотеза, не доказательство (just-world hypothesis / fallacy).
- Отдельный сигнал, если оба эксперта считают плохой исход доказательством вины или успех всегда заслуженным без калибровки.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.58.0` / versionCode `125`.

# 2.57.0 — Projection bias

- Добавлен `ProjectionBiasPolicy`. Проекция текущих предпочтений, вкусов или состояния на будущее без учёта адаптации или изменения ситуации — гипотеза, не доказательство (projection bias).
- Отдельный сигнал, если оба эксперта считают текущие ограничения неизменными без калибровки.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.57.0` / versionCode `124`.

# 2.56.0 — Dunning-Kruger / illusory superiority

- Добавлен `DunningKrugerPolicy`. Заявление высокой собственной компетентности, «очевидности для знающего» или превосходства без калибровки, признания границ знаний или base rate экспертизы — гипотеза, не доказательство (Dunning-Kruger / illusory superiority).
- Отдельный сигнал, если оба эксперта считают себя более компетентными без независимой калибровки.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.56.0` / versionCode `123`.

# 2.55.0 — Optimism bias

- Добавлен `OptimismBiasPolicy`. Систематическая переоценка вероятности хороших исходов и недооценка плохих (особенно для себя/плана) без базовой частоты неудач или независимой калибровки — гипотеза, не доказательство (optimism bias).
- Отдельный сигнал, если оба эксперта заявляют «всё получится» без оценки рисков.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.55.0` / versionCode `122`.

- Отдельный сигнал, если оба эксперта считают свою картину объективной.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.54.0` / versionCode `121`.
