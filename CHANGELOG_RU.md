# 2.39.0 — Appeal to ignorance

- Добавлен `AppealToIgnorancePolicy`. Вывод из «никто не опроверг обратное» или отсутствия доказательств без позитивного основания и явного бремени доказательства — гипотеза, не доказательство.
- Отдельный сигнал, если оба эксперта закрывают вывод тем, что оппонент не доказал обратное.
- `SynthesisProtocol` для решений просит не закрывать вывод отсутствием доказательств обратного. Координатор не закрывает метку таким сигналом.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.39.0` / versionCode `106`.

# 2.38.0 — Selection bias

- Добавлен `SelectionBiasPolicy`. Вывод из удобной, самоотобранной или усечённой выборки без учёта процесса отбора и base rate популяции — гипотеза, не доказательство.
- Отдельный сигнал, если оба эксперта опираются на отобранную выборку и не называют, кто не попал в наблюдение.
- `SynthesisProtocol` для решений просит учитывать отбор выборки. Координатор не закрывает метку выводом из нерепрезентативной выборки.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.38.0` / versionCode `105`.

# 2.94.0 — Narrative fallacy

- Добавлен `NarrativeFallacyPolicy`. Связная, яркая история не сильнее base rate, статистики и «грязных» данных.
- Отдельный сигнал, если оба эксперта закрывают вывод сюжетом вместо частоты класса.
- Развилка «история доказывает» против явной опоры на base rate / reference class не усредняется.
- Обычный пример из практики и названное разделение «история ≠ статистика» сигнал не поднимают.
- `SynthesisProtocol` для решений запрещает закрывать выбор историей вместо base rate. Координатор не переводит narrative fallacy в ДЕЛАТЬ или НЕ ДЕЛАТЬ.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION остаются 2.36.0 / versionCode 103 согласно CI.

# 2.86.0 — Эффект ореола (halo effect)

- Добавлен `HaloEffectPolicy`: локально отмечает перенос оценки одного качества на другое по несвязанному признаку — например, внешности, бренду, статусу или первому впечатлению — без самостоятельных доказательств.
- Отдельно отмечается, когда оба ответа используют такой признак как подтверждение другого качества.
- Сигналы требуют контекста и не являются вердиктом.

# 2.85.0 — Ошибка игрока (gambler's fallacy)

- Добавлен `GamblersFallacyPolicy`: выявляет предположение, что серия независимых событий должна «исправиться» или что противоположный исход стал вероятнее только из-за предыдущей серии.
- Учитывается явное признание независимости событий; обычное обсуждение последовательностей само по себе не помечается.
- Сигналы требуют контекста и не являются вердиктом.

# 2.84.0 — Эффект фрейминга

- Добавлен `FramingEffectPolicy`: отмечает расхождения между формулировками через выигрыш и потерю, а также относительными процентами и абсолютными величинами.
- Отдельно отмечается вывод, чувствительный к выбранной формулировке, если альтернативный фрейм не проверен.
- Сигналы требуют контекста и не являются вердиктом.

# 2.83.0 — Смещение авторитета

- Добавлен `AuthorityBiasPolicy`: выявляет опору на статус, титул или формулу «эксперты говорят» без разбора доказательств, механизма или базовых частот.
- Отдельно отмечается отклонение аргумента только по статусу источника.
- Сигналы требуют контекста и не являются вердиктом.

# 2.82.0 — Расширение многомаркерных проверок логических рисков

- Расширены локальные проверки `ReasoningFallacyPolicy` для апелляции к вероятности и сложных/нагруженных вопросов, где предпосылка скрыта внутри формулировки.
- Детекторы используют сочетания признаков и должны учитывать отрицание и контекст; совпадение одного слова не считается доказательством ошибки.
- Сигналы остаются гипотезами, а не автоматическими вердиктами.

# 2.81.0 — Регрессия к среднему

- Добавлен `RegressionToMeanPolicy`: отмечает трактовку экстремального результата как постоянного свойства или прогноз продолжения экстремума без поправки на естественную изменчивость и возврат к среднему.
- Если оба ответа игнорируют регрессию к среднему, это фиксируется отдельным сигналом.
- Сигналы требуют контекста и не являются вердиктом.

# 2.80.0 — Смещение выжившего

- Добавлен `SurvivorshipBiasPolicy`: выявляет выводы по видимым успехам без учёта невидимых неудач, отсева и базовой доли провалов.
- Отдельно отмечаются утверждения о тех, кто «добился успеха», без проверки того, кто не попал в выборку.
- Сигналы требуют контекста и не являются вердиктом.
