# 2.38.0 — Selection bias

- Добавлен `SelectionBiasPolicy`. Вывод из удобной, самоотобранной или усечённой выборки без учёта процесса отбора и base rate популяции — гипотеза, не доказательство.
- Отдельный сигнал, если оба эксперта опираются на отобранную выборку и не называют, кто не попал в наблюдение.
- `SynthesisProtocol` для решений просит учитывать отбор выборки. Координатор не закрывает метку выводом из нерепрезентативной выборки.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.38.0` / versionCode `105`.

# 2.94.0 — Narrative fallacy

- Добавлен `NarrativeFallacyPolicy`. Связная, яркая история не сильнее base rate, статистики и «грязных» данных.
- Отдельный сигнал, если оба эксперта закрывают вывод сюжетом вместо частоты класса.
- Развилка «история доказывает» против явной опоры на base rate / reference class не усредняется.
- Обычный пример из практики и названное разделение «история ≠ статистика» сигнал не поднимают.
- `SynthesisProtocol` для решений запрещает закрывать выбор историей вместо base rate. Координатор не переводит narrative fallacy в ДЕЛАТЬ или НЕ ДЕЛАТЬ.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION остаются 2.36.0 / versionCode 103 согласно CI.

# 2.93.0 — Ошибка конъюнкции

- Добавлен `ConjunctionFallacyPolicy`. Детальный сюжет или совпадение двух черт не вероятнее более широкого класса.
- Отдельный сигнал, если оба эксперта ставят конъюнкцию выше одиночного события.
- Развилка «история вероятнее класса» против явного предела конъюнкции не усредняется.
- Обычное сравнение базовых частот и названный предел сигнал не поднимают.
- `SynthesisProtocol` для решений запрещает считать сюжет вероятнее класса. Координатор не поднимает из этого уверенность и не закрывает метку.

# 2.92.0 — Эвристика аффекта

- Добавлен `AffectHeuristicPolicy`. Симпатия, отвращение или «хорошее чувство» не заменяют оценку риска и пользы.
- Отдельный сигнал, если оба эксперта закрывают вывод вкусом.
- Развилка «бесит, значит провалится» против явного отделения вкуса от риска не усредняется.
- Обычное предпочтение интерфейса и названная эвристика вместе с разделением сигнал не поднимают.
- `SynthesisProtocol` для решений запрещает закрывать выбор симпатией. Координатор не переводит её в ДЕЛАТЬ или НЕ ДЕЛАТЬ.

# 2.91.0 — Нечувствительность к масштабу

- Добавлен `ScopeInsensitivityPolicy`. Одна сила вывода для 10 и 10 000, или для деревни и страны, без отношения величин — гипотеза, не вердикт.
- Отдельный сигнал, если оба эксперта объявляют масштаб неважным.
- Названное отношение («в 100 раз», «на душу», «масштаб учтён») сигнал гасит.
- Обычный «эффект пилота небольшой» сигнал не поднимает.

# 2.90.0 — Ошибка бездействия (omission bias)

- Добавлен `OmissionBiasPolicy`. «Бездействие безопаснее» без сравнения ущерба от отказа действовать — гипотеза, не причина НЕ ДЕЛАТЬ.
- Отдельный сигнал, если оба эксперта считают бездействие безопасным само по себе.
- Развилка против явного ущерба от бездействия не усредняется.
- Обычное «подождём отчёт» сигнал не поднимает: это не отказ сравнивать вред.
- Модули 2.90–2.92 подключены в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION остаются 2.36.0 / versionCode 103 согласно CI.
