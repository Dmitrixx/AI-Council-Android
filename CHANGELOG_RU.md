# 2.56.0 — Dunning-Kruger / illusory superiority

- Добавлен `DunningKrugerPolicy`. Заявление высокой собственной компетентности, «очевидности для знающего» или превосходства без калибровки, признания границ знаний или base rate экспертизы — гипотеза, не доказательство (Dunning-Kruger / illusory superiority).
- Отдельный сигнал, если оба эксперта считают себя более компетентными без независимой калибровки.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.56.0` / versionCode `123`.

# 2.55.0 — Optimism bias

- Добавлен `OptimismBiasPolicy`. Систематическая переоценка вероятности хороших исходов и недооценка плохих (особенно для себя/плана) без базовой частоты неудач или независимой калибровки — гипотеза, не доказательство (optimism bias).
- Отдельный сигнал, если оба эксперта заявляют «всё получится» без оценки рисков.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.55.0` / versionCode `122`.

# 2.54.0 — Naive realism

- Добавлен `NaiveRealismPolicy`. Своя позиция как объективные факты, а несогласие — невидение или иррациональность без признания собственной перспективы — гипотеза, не доказательство.
- Отдельный сигнал, если оба эксперта считают свою картину объективной.
- Модуль подключён в `DeliberationSignals.detectAll`. Сигналы — гипотезы, требующие контекста. Gradle / APP_VERSION теперь `2.54.0` / versionCode `121`.
